# 必要诊断的触发与解释边界

本文件在首轮 full 结果产生前规定诊断问题，避免看见方向后挑选口径。不是自动展开的额外运行清单。主结果保持原配置；每项诊断单独登记输入、候选/实际对象、seed、参数变化、输出和限制。

| 触发证据 | 诊断问题 | 最小比较设计 | 能回答什么／不能回答什么 |
|---|---|---|---|
| 原生 EMT 的覆盖、基因轴或实际 cutoff 不同，且需解释跨侧分数差 | 分数差是否主要由评分背景改变？ | 固定首轮各侧评分对象与 seed，仅限制到两侧共同基因，记录交集 EMT 成员和各侧实际 cutoff；如 cutoff 仍不同，则先报告尚未控制该混杂，不能把共同基因自动称为可比 | 检查背景敏感性；不能证明参考扩展基因的空间真实性。任何固定 cutoff 的额外诊断须明确与原生 provider 的语义差别 |
| Raw/SVC 群数或群大小差异明显，且影响 State/Gain 解释 | Raw 群数匹配后 Gain 的方向与覆盖是否改变？ | 使用已有独立 Raw K-control 能力，保持输入、窗口、seed 和阈值；新目录完整 Impact，主结果不替换。报告目标 K、实际 K、群大小、有效窗口及变化 | 检查标签粒度解释；相同 K 不等于相同生物学分辨率 |
| donor 重复分配明显，表达结构被作为关键发现 | 结果是否依赖重复 donor 的权重？ | 先列各 scope/cluster 唯一 donor 数、复用分布及对应空间覆盖，再针对具体表达结论设计 donor-aware 权重或重抽样；保留空间单位与 donor 单位的区别 | 检查重复信息敏感性；不能把 reference donor 当作独立空间观测，也不能凭重复本身宣布方法失效 |
| 跨侧共同基因 Moran 成为关键表达结论，而覆盖或原生归一化背景可能影响方向 | 同一组织支持、相同基因背景下方向是否保留？ | 先保持首轮各侧单位cohort，仅限制相同共同基因再按既有方法归一化；若All覆盖仍影响核心解释，再单独增加共同ID、相同ID顺序的局部对照。三个parent原本已使用全部同ID单位。两步分开保存 | 控制局部覆盖与归一化基因背景；仍不消除测序技术、深度及reference转移的差异，不能将全流程强制配对 |
| 关键结论接近阈值或实际支持不足 | 单个明确参数变化是否改变关键判断？ | 先写具体疑点和一个参数变化，再运行独立诊断；全部结果留存 | 可以得出不稳健；不放松阈值、不补零、不以挑选最有利结果结束 |

每项诊断运行前补写“为何影响核心判断、保持什么不变、改变什么、结果如何改变结论”。若需要改变科学目标、输入选择或方法语义才能继续，形成具体选项提交用户。资源不足首先检查保持数值语义的实现优化；不以减少正式样本量替代 full。

实现核对（首轮结果前）：主流程的shared-gene Moran是在各侧完整原生基因轴归一化、计算后才取结果交集，因此它尚未控制归一化背景。Raw K-control若触发，需新增只允许该项参数差异的受控诊断入口；首轮冻结参数门保持不变。Gain阈值的n_windows是正差值窗口数，描述性审视仍读取完整正负差值。

Donor-aware EMT优先读取已保存逐单位分数，按审计过的assignment作1:1连接；报告单位加权均值、每donor先聚合后等权均值、donor数/复用分布/Kish有效donor数，并核同一donor在同一次评分中同分。该比较只检查同一SVC评分表的权重敏感性，不能将donor等权SVC直接与Raw单位加权分数称作同人群改善。Donor跨多个空间位置，不以每donor留一个点或聚合坐标后的Moran作为等价控制。

如果完整Raw因检测数低分位使AUCell cutoff无效，保留unavailable，不过滤低表达单位、不改cutoff、不补零。共同基因、共同ID与donor权重依次分开改变；已有结果足以解释时停止扩展诊断。
