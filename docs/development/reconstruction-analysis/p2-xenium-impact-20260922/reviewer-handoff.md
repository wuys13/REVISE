## 这项工作的本质

我们要回答的不是抽象的“重建成功了吗”，而是：**真实数据经过 REVISE 后变成了什么；Analysis Agent 对这些变化的分析是否成立；这些变化能支持什么、不能支持什么。** 技术链路只是必要条件。全量任务成功、三文件齐全、报告生成，均不能单独证明 SVC 恢复了真实空间表达或改善了生物学结果。

首轮对象是 `P2CRC_Xenium`，采用已固定的 random 重建和既定 Impact 参数，范围为 `All/Fibroblast/Mono_Macro/T`。REVISE 生产重建和来源声明；下游 Analysis Agent 独立消费其 `sample.yaml + raw.h5ad + SVC.h5ad` 交付并做 Impact。Raw 与 SVC 默认是两侧独立对象，不要求全局逐细胞配对。只有明确的局部问题才使用共同 ID；这种诊断不能倒过来把两侧解释成同一批测量或独立真值。

审视时要特别留意覆盖口径：Raw 为 `340,837 × 422`，SVC 为 `50,626 × 13,088`，SVC 行数约占 Raw 的 14.85%；SVC 实际包含 DC、Fibroblast、Mono_Macro、T，不含 Tumor/Intestinal epithelial。三个 parent 的 ID 集合相同，但 `All` 两侧是各自独立的 30,000 单位抽样，共同 ID 只有 4,506 个。因此 parent 内局部比较与 All 比较的适用范围不同，不能把 All 差异直接外推成全组织效果，也不能用局部共同 ID 诊断把全局分析改写成配对研究。

关键机制是 random SVC 的表达来自同群参考细胞 donor。表达来源完全可追溯，意味着表达扩展或结构变化可能是参考信息转移的结果，不等于新增了 Xenium 原位证据。因此，对 State/Gain、Moran、EMT、Anatomy 等方向的解释都需要审查各自的对象、背景、分母和来源；**不预设变化应当更好，也不为了得到更正面的结果放松阈值、补零或挑选参数。**
